COMPUTER VISION LAB - 40 EXPERIMENTS

This project contains one folder for each of the 40 experiments in the supplied
Computer Vision Experiments list.

The common sample_image.jpg and sample_video.avi are in this main folder.
Most programs automatically find them using the project folder path.

Install:
    pip install -r requirements.txt

Then open the Computer_Vision_Lab folder in VS Code.

Experiments 7, 38 and 39 use the webcam.
Experiment 36 needs a real watch_template.jpg for actual watch recognition;
the supplied experiment list did not include a watch image, so that file was
not invented.
